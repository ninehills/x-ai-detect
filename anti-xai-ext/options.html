决策 API 供应商与密钥（必填）

本扩展仅通过决策 API 进行 AI Slop 探测，不依赖本地关键词/规则。默认供应商为 Jev，也可切换为 Gemini（gemini-decision-1）。

探测设置

扩展仅从回复页 DOM 抽取 6 个公开字段（原帖正文、作者显示名/@handle/蓝V标记、回复正文、是否含媒体），绝不主动请求任何 X 接口，不执行任何隐藏或屏蔽操作。

提示词与阈值 JSON（与标注系统对齐）

与标注系统的 prompt_config.json 格式完全一致，可在回归页调优后直接复制 JSON 粘贴到此处导入，或导出给标注系统使用。

白名单（标为误判的账号）

白名单内的账号不会被探测或一键屏蔽。
