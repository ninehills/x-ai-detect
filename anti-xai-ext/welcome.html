欢迎使用 Anti-XAI

基于决策 API 探测 X（推特）评论区的 AI Slop 回复。默认仅探测并在每条回复上标注 AI 率，不自动隐藏或屏蔽。

项目来源与致谢
本扩展基于 Chrome 扩展 X 黄推屏蔽器 二次改造而来，在此基础上改为 AI Slop 回复探测、移除本地规则与云端共享屏蔽库、支持 Jev / Gemini 多供应商与一键屏蔽。
1配置决策 API 供应商与密钥（必填）

本扩展完全依赖决策 API 探测 AI Slop，不使用本地规则，也不连接任何云端共享屏蔽库。默认供应商为 Jev，也可切换为 Gemini（gemini-decision-1）。

2工作方式说明
  • 打开任意 X 帖子详情页，扩展仅从页面 DOM 读取回复信息并在每条回复右上角标注 🤖 AI xx%。
  • 纯只读模式：不主动请求任何 X 接口，不自动隐藏，不执行任何屏蔽操作。
  • 可在设置页直接导入/导出与标注系统对齐的 prompt_config.json。
